# Sisyphus 算法理论支撑文档

> 基于学术研究和科学理论，为Sisyphus四大核心算法提供理论依据。

---

## 一、间隔重复（FSRS）理论基础

### 1.1 Ebbinghaus遗忘曲线（1885）

**来源**：Hermann Ebbinghaus, *Uber das Gedachtnis*（论记忆），1885年

**数学模型**：`R = e^(-t/S)`
- R = 记忆保持率（0~1）
- t = 距上次学习的时间
- S = 记忆强度（stability）

**含义**：记忆随时间呈指数衰减，每次有效复习重建记忆强度，使衰减曲线变缓。

### 1.2 间隔效应（Spacing Effect）

**来源**：Cepeda, Pashler, Vul, Wixted & Rohrer (2006), "Distributed practice in verbal recall tasks: A review and quantitative synthesis", *Psychological Bulletin*, 132(3), 354-380

**核心发现**：最优复习间隔约为期望保持期的10-20%。
- 想记住1年 → 约1-2个月后复习
- 想记住1周 → 约1天后复习

### 1.3 FSRS的DSR模型

**来源**：Jarrett Ye（叶峻峣），FSRS-4.5/FSRS-5，2023年，GitHub: open-spaced-repetition/fsrs4anki

三个参数建模记忆（比SM-2的单一EF更精确）：

| 参数 | 含义 | 理论依据 |
|------|------|----------|
| **Difficulty (D)** | 卡片固有难度（1-10） | 材料难度对遗忘速率的影响 |
| **Stability (S)** | 记忆保持率从100%降到90%所需天数 | Ebbinghaus的S参数变体 |
| **Retrievability (R)** | 当前回忆概率 | 遗忘曲线的实时预测值 |

**核心公式**：

回忆概率衰减（幂函数遗忘曲线，比指数衰减更符合实证数据）：
```
R(t) = (1 + t/(9*S))^(-1)
```

初始稳定性：
```
S₀(G) = w₁ · e^(w₂ · G)    （G = 评分等级）
```

初始难度：
```
D₀(G) = w₄ - (e^(w₅·G) - 1) · (w₆·(G-1))
```

成功回忆后的稳定性更新：
```
S' = S · (e^w₈ · (11-D) · S^(-w₉) · (e^(w₁₀·S)-1) · hard_penalty · easy_bonus + 1)
```

遗忘后的稳定性更新：
```
S' = w₁₁ · D^(-w₁₂) · ((S+1)^w₁₃ - 1) · e^(w₁₄·(1-R))
```

FSRS有19个可调参数（w₁~w₁₉），通过用户实际复习数据用机器学习拟合。

### 1.4 对Sisyphus的指导

| 设计决策 | 理论依据 |
|----------|----------|
| 新用户先用SM-2过渡 | SM-2无需数据积累，冷启动可用 |
| 积累数据后切换FSRS | FSRS需要~1000次复习数据才能有效拟合参数 |
| 默认目标保持率0.9（90%） | Cepeda研究：90%保持率对应合理的复习工作量 |
| 得分率低→间隔更短 | Difficulty高→Stability增长慢→需更频繁复习 |

**推荐默认参数**：
- 目标保持率（request retention）：**0.90**（标准）或 **0.85**（宽松模式）
- FSRS参数：使用Anki默认参数作为冷启动，积累数据后optimize
- SM-2过渡期EF默认值：**2.5**

## 二、经验值/等级系统理论基础

### 2.1 自我决定论（SDT）

**来源**：Edward Deci & Richard Ryan, *Intrinsic Motivation and Self-Determination in Human Behavior*, 1985

三大心理需求：
- **自主性（Autonomy）**：感觉对行为有控制权
- **胜任感（Competence）**：感觉有能力达成目标
- **关联性（Relatedness）**：感觉与他人有连接

**对XP设计的指导**：XP系统提供增量反馈满足胜任感需求，但外在奖励（XP/徽章）可能削弱内在动机（过度理由效应）。XP应作为"信息性反馈"而非"控制性奖励"。

### 2.2 心流理论（Flow Theory）

**来源**：Mihaly Csikszentmihalyi, *Flow: The Psychology of Optimal Experience*, 1990

核心：当**挑战水平与技能水平匹配**时产生心流状态。
- 太简单 → 无聊
- 太难 → 焦虑

**对XP曲线的指导**：等级间距应随等级增加而增大，但不能大到让用户感到"永远达不到"。

### 2.3 练习幂律（Power Law of Practice）

**来源**：Newell & Rosenbloom (1981), "Mechanisms of Skill Acquisition and the Law of Practice", in *Cognitive Skills and Their Acquisition*

公式：`T = a · N^(-b)`
- T = 任务完成时间
- N = 练习次数

含义：技能提升初期快速，随后边际收益递减——直接解释了为什么XP曲线应是凹函数（对数型或幂函数型）。

### 2.4 Bloom的2 Sigma问题

**来源**：Benjamin Bloom, "The 2 Sigma Problem", *Educational Researcher*, 1984, 13(6), 4-16

发现：一对一辅导+掌握学习 → 比传统教学高**2个标准差**（从50百分位到98百分位）。

**对等级系统的指导**：等级应与实际能力挂钩（如Sisyphus的"等级-高考得分率映射"），而非仅与学习量挂钩。

### 2.5 XP曲线数学模型

| 模型 | 公式 | 特点 |
|------|------|------|
| **幂函数型** | XP_needed = base × level^exponent | 最常见，符合练习幂律 |
| **对数型** | XP_needed = a × ln(level) + b | 前期快后期极慢 |
| **S型（Logistic）** | XP_needed = K / (1 + e^(-r(level-mid))) | 前慢中快后慢 |
| **分段线性** | 不同等级段不同斜率 | 灵活但不平滑 |

### 2.6 对Sisyphus的指导

| 设计决策 | 理论依据 |
|----------|----------|
| 等级-得分率硬性映射 | Bloom：等级应反映真实能力水平 |
| XP曲线自动拟合而非固定 | SDT：避免外在奖励控制，保持内在动机 |
| 每10级一个称号 | 胜任感需求：里程碑反馈维持动机 |
| 早期快速升级 | 心流理论：初期匹配低技能，快速获得掌控感 |
| 后期间距增大但不失望 | 练习幂律：技能提升自然放缓，用户可理解 |

**推荐默认参数**：
- 1-10级：XP需求增速低（建立信心）
- 11-40级：线性增长
- 41-70级：幂函数增长（指数≈1.5）
- 71-100级：增速放缓（指数回降到1.2）
- 称号体系：每10级一个，共10个

## 三、推荐算法理论基础

### 3.1 贝叶斯知识追踪（BKT）

**来源**：Corbett & Anderson (1995), "Knowledge Tracing: Modeling the Acquisition of Procedural Knowledge", *User Modeling and User-Adapted Interaction*

模型：隐马可夫模型（HMM），4个参数：
- P(L₀) — 先验知识概率
- P(T) — 学习转移概率
- P(G) — 猜对概率
- P(S) — 失误概率

特点：可解释性强，每个技能独立建模。局限：假设技能间独立。

### 3.2 深度知识追踪（DKT）

**来源**：Piech et al. (2015), "Deep Knowledge Tracing", *NeurIPS*

模型：LSTM/GRU循环神经网络。优势：能捕捉学习序列中的非线性关系。局限：可解释性差，需要大量数据。

### 3.3 知识追踪模型演进

| 模型 | 年份 | 类型 | 关键特征 |
|------|------|------|----------|
| BKT | 1995 | HMM | 可解释，4参数/技能 |
| DKT | 2015 | LSTM | 序列建模，高精度 |
| DKT+ | 2016 | 改进LSTM | 解决DKT不一致性 |
| AKT/SAINT | 2020 | Transformer | 注意力机制 |
| DAS3H | 2019 | 贝叶斯+神经 | 可解释+性能兼顾 |

### 3.4 背包问题建模

将学习推荐建模为带约束的优化问题：
- **背包容量** = 用户可用学习时间
- **物品** = 各知识点/学科的学习任务
- **物品重量** = 完成该任务所需时间
- **物品价值** = 该任务的预期学习收益（提分潜力 × 紧急度）
- **目标**：在时间预算内最大化总学习收益

数学形式：
```
max Σ(vᵢ · xᵢ)  subject to Σ(wᵢ · xᵢ) ≤ T, xᵢ ∈ {0,1}
其中：
  vᵢ = 知识点i的提分潜力 × 学科权重
  wᵢ = 知识点i的预估学习时长
  T = 用户可用总时间
```

### 3.5 提分潜力计算

```
提分潜力 = (目标得分率 - 当前得分率) × 知识点权重 × 时间敏感度
```

时间敏感度考虑：
- 距考试时间（越近越紧急）
- 遗忘曲线（越久没复习越紧急）
- 学科分值权重（高考分值占比）

### 3.6 对Sisyphus的指导

| 设计决策 | 理论依据 |
|----------|----------|
| 阴影队列（Shadow Queue） | 简化版BKT：追踪每个知识点的掌握状态 |
| 时间预算推荐用背包算法 | 经典组合优化，NP-hard但贪心近似足够 |
| 3-5个推荐任务 | 认知负荷理论：工作记忆容量7±2，推荐过多反而降低决策质量 |
| 学科权重可手动+自动 | SDT自主性：用户有控制权，系统有智能默认 |
| 提分潜力排序 | 优化目标：单位时间收益最大化 |

**推荐默认参数**：
- 推荐任务数：**3-5个**（默认3个）
- 背包算法：贪心近似（按"价值/重量"比排序，O(n logn)）
- 阴影队列更新频率：每次学习记录提交后实时更新
- 提分潜力权重公式：`score_gap × subject_weight × urgency_factor`
- urgency_factor：`1 / (1 + days_since_last_review/7)`（7天未复习紧急度翻倍）

## 四、输入输出比例理论基础

### 4.1 测试效应（Testing Effect）

**来源**：Roediger & Karpicke (2006), "Test-Enhanced Learning: Taking Memory Tests Improves Long-Term Retention", *Psychological Science*, 17(3), 249-255

核心发现：**主动回忆（测试自己）比被动复习（重读材料）显著提高长期记忆保持率**。

实验：两组学生，一组通过测试学习，一组通过重读学习。
- 短期（即时测试）：重读组略好
- **长期（1周后测试）：测试组显著优于重读组**

关键结论：测试不仅是评估手段，**测试本身就是最有效的学习方式**。

### 4.2 主动回忆 vs 被动复习

| 维度 | 输入型学习（被动） | 输出型学习（主动） |
|------|-------------------|-------------------|
| 方式 | 阅读、听讲、看视频 | 做题、默写、教别人 |
| 认知加工 | 浅层编码 | 深层检索+重构 |
| 元认知 | 容易产生"能力错觉" | 准确评估掌握程度 |
| 记忆效果 | 短期好，长期衰减快 | 短期费力，长期保持好 |
| 机制 | 重复暴露（familiarity） | 检索练习（retrieval practice） |

### 4.3 学习金字塔的科学性

学习金字塔（NTP金字塔）声称的具体百分比（如"阅读记住10%，讲授记住90%"）**缺乏严格实验支撑**，原始来源不明。

但其核心方向——**输出比输入更有效**——有坚实实验支持：
- Roediger & Butler (2011), "The critical role of retrieval practice in long-term retention", *Trends in Cognitive Sciences*
- Karpicke & Roediger (2008), "The critical importance of retrieval for learning", *Science*

### 4.4 生成效应（Generation Effect）

**来源**：Slamecka & Graf (1978)

含义：**自己生成的信息比被动接收的信息记忆更深**。

### 4.5 刻意练习（Deliberate Practice）

**来源**：K. Anders Ericsson (Florida State University)

核心：**有目的、有反馈、在能力边缘的练习**比简单重复有效得多。强调输出的"质"——不是所有输出都等价，需要有反馈的、渐进式的练习。

### 4.6 为什么是70/30而非50/50

学术研究没有直接给出"70/30"精确比例，但支持"输出应占多数"：

1. **元分析证据**：检索练习优于重读（Roediger & Butler, 2011）
2. **学习者偏差**：学习者天然倾向于过度消费输入，系统需主动纠正
3. **边际收益递减**：输入型学习收益随时间递减更快
4. **刻意练习**：专家级表现主要来自有反馈的输出练习

**70/30是合理的设计启发式**，其价值在于纠正学习者"输入过多"的自然倾向。

### 4.7 对Sisyphus的指导

| 设计决策 | 理论依据 |
|----------|----------|
| 每日/每学科计算输入输出比 | 宏观+微观两个层面捕捉偏科 |
| 输出>70%时不提醒 | 比例健康，无需干预 |
| 输入>70%时柔和提醒 | 检测到"能力错觉"风险 |
| 长期失衡→强烈提醒 | 持续偏差说明学习策略问题 |
| 番茄钟完成后建议"输出型任务" | 测试效应：输入后立即输出效果最佳 |

**推荐默认参数**：
- 目标比例：**30%输入 / 70%输出**
- 柔柔提醒阈值：输入占比 > 50%
- 强烈提醒阈值：输入占比 > 70% 且持续3天以上
- 学科层面：独立计算，每个学科有自己的输入输出比

## 五、四大算法的理论交叉

```
遗忘曲线 (Ebbinghaus) ──→ 间隔重复 (FSRS)
       │                        │
       │                        ├── S参数 = 记忆强度
       │                        ├── D参数 = 材料难度
       │                        └── R参数 = 当前回忆概率
       │
       ├──→ 测试效应 (Roediger) ──→ 输入输出比例 (70/30)
       │         │
       │         └── 主动回忆 > 被动复习
       │
       └──→ 练习幂律 (Newell) ──→ XP曲线设计
                 │
                 ├── 初期快速提升 → 早期XP增速高
                 └── 后期边际递减 → 后期XP需求增大
                 
知识追踪 (BKT/DKT) ──→ 背包推荐算法
       │                      │
       ├── 掌握状态建模         ├── 时间预算 = 背包容量
       └── 提分潜力计算         └── 学习收益 = 物品价值

自我决定论 (SDT) ──→ 等级系统 + 推荐系统
       │
       ├── 自主性 → 用户可调权重/参数
       ├── 胜任感 → XP反馈/等级称号
       └── 关联性 → （未来社交功能）
```
